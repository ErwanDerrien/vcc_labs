# vcc_labs
# 1. Expliquez, avec vos propres mots, ce qu’est une machine virtuelle.
Une machine virtuelle est un ordinateur virtuel que tu utilise des ressource d'une ordinateur physique, tu peux utiliser toute les ressources ou seulement une partie pour que sur le même ordinateur ( ou autre) avoir plusieurs machine virtuelle, chacune pouvant utiliser son propre système d'exploitation.
# 2. Citez deux avantages de la virtualisation dans un environnement professionnel.
- Elle permet d'utiliser plus efficacement les ressources de l'ordinateurs physique, en ayant plusieurs machines virtuelles sur le même ordinateur phyisque.
- Elle permet d'isoler les différentes machines virtuelles donc elles ne s'Affectent pas entre elles.
# 3. Quelle différence existe-t-il entre travailler directement sur votre ordinateur et travailler dans une machine virtuelle?
Quand on travaille directement sur notre ordinateur, on utilise directement son système d'exploitation et ses ressources physiques. Dans une machine virtuelle on utilise son propre système d'exploitation mais qu'une partie des ressources phyisques.
